# RLM v1.7.1 — Quick bug fix

This update fixes two match-start problems reported after v1.7.0.

- **Matches stuck at 4/5 bots ready:** local matches now detect failures during bot initialization or the first control output, keep kickoff paused, replace the failed policy with a healthy alternative, and check all bots again before starting. Replacements are temporary and leave saved player ratings and intended bot choices unchanged. If no supported alternative works, RLM stops with an error instead of starting an incomplete match.
- **Muted-commentary crash:** fixed `'ClipBroadcast' object has no attribute 'prepare_intro'` during Rocket Host startup when commentator voices are disabled. Crowd reactions and countdown audio can remain enabled without requiring generated introductions.
- **Player introductions:** recorded-only commentary no longer trips a missing shutdown-state check during the player-card sequence.
- **Unavailable-bot fallbacks:** substitutions use the closest supported healthy tiers, with weaker choices preferred on equal-distance ties. Temporary hosted replacements no longer overwrite the intended series assignment.

## Updating

Close **RL Manager and Rocket League**, then install **RL.Manager.1.7.1.Setup.exe**. Existing users do not need to reinstall the complete runtime kit or delete saves/settings.

New players should follow the [first-time installation guide](https://github.com/ItsAminus/rl-manager#start-here-first-time-installation): install the complete base kit, then the latest app installer.

These changes address the diagnosed startup failures. Unrelated bot, Rocket Host or connection failures may still require a support log.
