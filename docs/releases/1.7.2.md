# RLM v1.7.2 — Match startup fixes

- **Local bot-control crash fixed:** tactics reports now convert NumPy controller values into JSON-safe values. This resolves the reported `bool_`, `int64` and related serialization errors that could interrupt bot output and prevent readiness. A diagnostic reporting failure no longer discards valid controls.
- **Hosted spectator/2v3 recovery:** RLM requests human team entry once the correct five bot slots are present, without waiting for every bot-name alias to match first. Career identity verification remains separate, so unknown bot names are not used to guess player statistics.
- **Early-start protection:** if the hosted server scores or advances too far before the human joins, RLM retries the same game rather than leaving the player watching an incomplete match. Team-entry and identity failures have bounded recovery; unrecoverable attempts stop without recording a result.
- **Loading-screen recovery:** the loading cover closes when a failed attempt returns to RLM for recovery. Normal match readiness still requires confirmation of all six career roles, including the locally controlled human.

## Updating

Close **RL Manager and Rocket League**, then install **RL.Manager.1.7.2.Setup.exe**. Existing users only need this app installer. Keep your existing runtime, saves and settings.

New users should follow the [first-time installation guide](https://github.com/ItsAminus/rl-manager#start-here-first-time-installation), installing the complete base kit followed by the latest app update.

The tactics crash was reproduced from the supplied log and regression-tested. Hosted entry recovery is covered by automated tests; it has not yet been verified on the affected player's PC. Unrelated Rocket Host or connection problems may still require a support log.
